# لوحة بغداد لإدارة الحوادث

موقع ثابت بواجهة عربية وإنجليزية، مبني باستخدام HTML وCSS وJavaScript وLeaflet وChart.js. لا يحتوي على حوادث مسبقة أو بيانات محاكاة أو خادم خلفي.

## التشغيل على Windows 11

1. افتح مجلد المشروع في مستكشف الملفات.
2. اكتب `powershell` في شريط عنوان المجلد واضغط Enter.
3. شغّل خادم الملفات:

   ```powershell
   python -m http.server 8000
   ```

   إذا لم يتعرف Windows على `python`، جرّب `py -m http.server 8000`.
4. افتح <http://localhost:8000/> في المتصفح. أوقف الخادم باستخدام Ctrl+C.

تحتاج ملفات Leaflet وChart.js وخرائط OpenStreetMap إلى اتصال بالإنترنت. كما يعمل الموقع الثابت على GitHub Pages دون Python أو خطوة بناء، بعد نشر ملفات المشروع.

## إدارة البيانات والخصوصية

- ابدأ بإضافة سجلاتك عبر نموذج إدارة الحوادث. لا توجد سجلات افتراضية.
- نموذج الإضافة المختصر يطلب العنوان والنوع والمنطقة والتاريخ وإحداثيات XY أو MGRS والأهمية. رقم الحادث يُنشأ تلقائياً؛ حالة السجل الجديدة «مفتوحة» والمحافظة الافتراضية بغداد.
- الوصف والملاحظات والعنوان النصي والوقت والصورة متاحة داخل تفاصيل اختيارية مطوية، ولا تطيل نموذج الإضافة الأساسي.
- أدخل الإحداثيات في خانة XY بهذا الترتيب: `X, Y` أي `خط الطول، خط العرض`، مثل `44.3661, 33.3152`. أو أدخل مرجع MGRS وحده في خانته؛ تُحوّل مكتبة MGRS المرجع إلى إحداثيات الخريطة وتحفظ الصيغة الأصلية أيضاً. يجب أن يتصل المتصفح بالإنترنت لتحميل مكتبة التحويل.
- عند تحريك المؤشر فوق الخريطة، يعرض الشريط السفلي X وY ومرجع MGRS للموقع الحالي. أُزيل اختيار نقطة الخريطة من نموذج الحادث؛ أدخل الإحداثيات في حقول النموذج.
- تظهر علامات الخريطة من الإحداثيات المحفوظة نفسها. نافذة العلامة تعرض العنوان والنوع والتاريخ والمنطقة، وزر «تحديد الموقع على الخريطة» في صف السجل يقرّب الخريطة إلى العلامة.
- تُحفظ الحوادث والمرفقات في IndexedDB على الجهاز والمتصفح الحاليين. تحديث الصفحة لا يحذفها، لكنها لا تنتقل تلقائياً إلى جهاز أو متصفح آخر.
- استخدم تنزيل JSON لإنشاء نسخة احتياطية تتضمن المرفقات. استيراد JSON يضيف السجلات ويتحقق من الحقول والمعرّفات المكررة.
- تصدير CSV ينشئ ملفاً يمكن فتحه في Excel. لا يتضمن CSV بيانات الصورة.
- لا يحتوي الموقع على تسجيل دخول أو تشفير أو مزامنة. تجنب إدخال البيانات الشخصية أو السرية أو أي معلومات لا ينبغي أن تكون متاحة على جهاز المستخدم.
- تظهر العلامة على الخريطة فقط إذا أدخل المستخدم خطي العرض والطول الصحيحين. استخدم فقط إحداثيات مصرحاً بعرضها؛ لا تستخدم مواقع انتشار أو تفاصيل تشغيلية حساسة.
- الإحصاءات مشتقة من السجلات المحفوظة والفلاتر الحالية. الأعداد والمقارنات الوصفية ليست معدلات مخاطر ولا دليلاً على سلامة منطقة أو عدمها. لا تتوفر بيانات لتغطية الخدمات ما لم تُضف ميزة إدخالها.
- أولويات التقييم المعروضة عتبات وصفية قابلة للشرح: مراجعة عالية عند وجود ٣ سجلات على الأقل منها سجلان مرتفعا الأهمية، ومتوسطة عند وجود سجل مرتفع الأهمية أو ٣ سجلات، واعتيادية فيما عدا ذلك. هذه العتبات لا تقيس الخطر أو السلامة، ولا توصي بنشر موارد أو استهداف أي شخص.

## GitHub Pages

1. أنشئ مستودعاً عاماً أو خاصاً على GitHub حسب خطتك.
2. باستخدام GitHub Desktop اختر **File → Add Local Repository** وحدد مجلد المشروع. إذا لم يكن المستودع مهيأ، أنشئ مستودعاً في المجلد نفسه.
3. راجع الملفات قبل الإرسال. لا تضف أي سجلات فعلية أو نسخ احتياطية خاصة.
4. أنشئ commit ثم اختر **Publish repository**.
5. في صفحة المستودع اذهب إلى **Settings → Pages**.
6. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)` واضغط **Save**.
7. بعد اكتمال النشر، افتح الرابط الذي تعرضه إعدادات Pages واختبر الوظائف.

لم يتم نشر الموقع أو التحقق من رابط عام في هذا المشروع. البيانات المضافة عبر المتصفح تبقى محلية؛ نشر الموقع لا يجعل سجلات مستخدم تنتقل للزوار الآخرين. لا تضع ملفات النسخ الاحتياطي في مستودع عام.

## الملفات

- `index.html` — واجهة الموقع ونموذج الحوادث والأدوات.
- `styles.css` — التصميم المتجاوب والهوية الحالية.
- `app-local.js` — IndexedDB، إدارة السجلات، الفلاتر، الرسوم، الخريطة، والاستيراد والتصدير.
- `data/ministry-of-interior-iraq.png` — الشعار المحلي الموجود في المشروع.
- `.nojekyll` — إعداد GitHub Pages للمحتوى الثابت.

## التوافق والحدود

تتطلب الخريطة والرسوم الاتصال بالإنترنت لجلب المكتبات والخرائط من مزوديها العموميين. لا توجد قاعدة بيانات خارجية أو خدمات مدفوعة أو مفاتيح سرية. يتطلب الاتصال بـOpenStreetMap مراعاة سياسة الاستخدام والإسناد الخاصة بهم. IndexedDB تخزين محلي ضمن المتصفح وليست قاعدة بيانات مشتركة أو نظام نسخ احتياطي؛ نزّل نسخة JSON واحتفظ بها في مكان آمن.
