بيانات محاكاة

استورد ملفات جداول أو بيانات جغرافية مصرحاً بها ومنزوعة الهوية. تبقى البيانات في جلسة المتصفح؛ استخدم إحداثيات عامة أو مجمعة قبل المشاركة.

الحقول المطلوبة: المعرّف، التاريخ، المنطقة، الفئة، الشدة، الحالة، خط العرض، خط الطول.
أعمدة الملف الجدوليid,date,district,category,severity,status,latitude,longitude
بيانات جغرافية بصيغة جيوجيسونFeatureCollection → Point; [longitude, latitude]

لا تستورد معرّفات شخصية أو تفاصيل تشغيلية حساسة أو مواقع انتشار دقيقة أو سجلات سرية. لا يحتوي هذا التطبيق الثابت على مصادقة أو سجل تدقيق أو تخزين آمن.
